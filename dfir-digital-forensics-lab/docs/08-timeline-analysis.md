# 08 — Timeline Analysis and Correlation

## 1. Purpose

A timeline organizes observations from different sources into a common chronological view. It helps investigators test sequences, identify gaps, and connect host, identity, network, and application activity.

## 2. Normalization

For each event, preserve:
- Original timestamp and timezone if available.
- Normalized timestamp, commonly UTC.
- Source system and source artifact.
- Event identifier and description.
- Actor, host, process, IP, or resource where available.
- Original evidence reference and collection context.

Never silently discard the original timestamp. If timezone is unknown, label it unknown rather than guessing.

## 3. Clock issues

Systems may have clock drift, incorrect timezone settings, delayed log delivery, or timestamps generated by different components. A log ingestion timestamp is not necessarily the event occurrence time. Record clock uncertainty and avoid false precision.

## 4. Correlation example

Suppose the following synthetic sequence appears:
- 09:00 UTC — a user signs in.
- 09:04 UTC — a new process starts.
- 09:06 UTC — the host makes an outbound DNS query.
- 09:08 UTC — an alert is generated.

This sequence may justify further investigation, but timing alone does not prove that the process caused the DNS query or that the activity was malicious. Additional process, network, and user context is required.

## 5. Practical workflow

1. Export a small set of events from an authorized lab.
2. Preserve each source file and calculate its hash.
3. Map fields into a common CSV schema.
4. Normalize timezone only when the source timezone is known.
5. Run `scripts/timeline_builder.py`.
6. Review ordering and identify missing or ambiguous timestamps.
7. Cite each important timeline event by evidence ID and source.
8. Write a conclusion that separates facts from interpretation.

The supplied script sorts ISO-8601 timestamps lexically. Use consistently normalized ISO-8601 values (prefer UTC with `Z`) for reliable chronological sorting. It is a simple learning utility, not a full forensic timeline engine.
