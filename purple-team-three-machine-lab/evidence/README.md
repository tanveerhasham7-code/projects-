# Evidence Folder

Add screenshots and sanitized text evidence after performing each exercise.

Suggested screenshots:
1. Hypervisor network settings showing the isolated network.
2. Three-machine asset inventory (hide sensitive host details if needed).
3. Wazuh agent health showing Windows and Ubuntu agents.
4. Windows Security event in Event Viewer.
5. Sysmon process event in Event Viewer.
6. Ubuntu authentication event.
7. Kali limited scan output for the Ubuntu lab target.
8. Ubuntu access log showing harmless HTTP requests.
9. Matching Wazuh event or alert.
10. Completed investigation timeline.

Suggested naming:
- 01-isolated-network.png
- 02-agent-health.png
- 03-windows-security-event.png
- 04-sysmon-process-event.png
- 05-ubuntu-auth-event.png
- 06-kali-lab-scan.png
- 07-ubuntu-access-log.png
- 08-wazuh-alert.png
- 09-investigation-timeline.png

Before upload, redact secrets, tokens, real credentials, personal information, and any infrastructure details you do not want public. Never create a screenshot to represent an event that did not occur.
