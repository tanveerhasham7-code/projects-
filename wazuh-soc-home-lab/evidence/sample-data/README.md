# Sanitized Sample Data

Store only synthetic or sanitized sample events here. Each dataset must include:
- A note stating whether it is synthetic or sanitized.
- The event source and relevant platform/version.
- Field descriptions where needed.
- The expected use case.
- Confirmation that no secrets or personal data are present.

Do not upload raw production logs or logs from systems you do not own or have permission to share.

**Current status:** no lab-collected datasets have been added.
